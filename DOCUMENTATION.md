# Student Performance Analytics System

## 1. Introduction
The Student Performance Analytics System is a Python-based project that analyzes students' marks and generates useful performance reports. It uses NumPy and Pandas to process student data and calculate results.

## 2. Objectives
- To store and analyze student marks.
- To calculate total marks and average marks.
- To assign grades to students.
- To identify the top-performing student.
- To generate an output CSV file containing analysis results.

## 3. Technologies Used
- **Python:** Main programming language.
- **Pandas:** Used to read, process, and analyze student data.
- **NumPy:** Used for numerical operations.
- **CSV:** Used to store input and output data.
- **Visual Studio Code:** Used to write and run the program.
- **GitHub:** Used to store and share the project.

## 4. Project Files
- `main.py` – Contains the Python program.
- `students.csv` – Contains the sample student data.
- `student_analysis.csv` – Stores the analyzed student results.
- `README.md` – Provides a brief project overview.
- `DOCUMENTATION.md` – Contains the project documentation.

## 5. Working Methodology
1. Read student information from `students.csv`.
2. Process the marks using Pandas and NumPy.
3. Calculate each student's total and average marks.
4. Assign grades based on the program's grading rules.
5. Identify the highest-performing student.
6. Save the analyzed results in `student_analysis.csv`.
7. Display a summary of class performance.

## 6. Concepts Covered
- Variables and data types
- Loops and conditional statements
- Functions
- NumPy arrays and numerical calculations
- Pandas DataFrames
- Reading and writing CSV files
- Basic data analysis

## 7. Results
The program was tested using sample data for 10 students.

- Number of students: 10
- Class average: 75.07
- Highest individual average: 95.33
- Lowest individual average: 47.67
- Top performer: Simran
- Top performer's average: 95.33

The program generates an output CSV file containing the analyzed student results.

## 8. How to Run the Project
1. Install Python on your computer.
2. Install the required libraries by running:

   `python -m pip install pandas numpy`

3. Open the project folder in Visual Studio Code.
4. Open the terminal in the project folder.
5. Run the program using:

   `python main.py`

6. Check the terminal output and the generated `student_analysis.csv` file.

## 9. Advantages
- Makes student data analysis easier.
- Reduces manual calculations.
- Provides a clear summary of class performance.
- Stores results in a CSV file for future reference.

## 10. Conclusion
The Student Performance Analytics System demonstrates how Python, NumPy, and Pandas can be used to analyze student marks. The project helped practice programming fundamentals, data processing, CSV file handling, and basic data analysis.
